# Pedro Henrique Peixoto — Portfolio

> Personal portfolio and developer showcase built with **React and Vite**, designed to present my experience, technical skills, projects, and ongoing development journey.

## About

This repository contains my personal portfolio, where I showcase my work as a **Systems Information student and software developer** with a focus on backend development and modern web technologies.

The portfolio was originally developed as a single-page HTML/CSS/JavaScript project and was later migrated to **React + Vite**, introducing a more modular, maintainable, and scalable architecture.

The goal is not only to present my projects, but also to use the portfolio itself as a practical demonstration of the technologies and development practices I am learning.

## Running Locally

Clone the repository:

```bash
git clone https://github.com/pedroalmeidapeixoto/pedro-portfolio.git
```

Navigate to the project:

```bash
cd pedro-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```
